# Nexus Admin Dashboard

A modern admin dashboard built with React and Vite, designed to provide a clean, organized, and responsive interface for administrative workflows.

## Overview

**Nexus Admin Dashboard** is a frontend project focused on building a maintainable dashboard interface with reusable UI components and a structured React application.

The project demonstrates practical frontend development skills, including component-based architecture, UI organization, and modern development workflows.

## Features

- **Modern UI** — A clean dashboard layout designed for usability.
- **Reusable Components** — Modular React components for easier maintenance.
- **Account Creation Interface** — A dedicated page for the account creation flow.
- **Responsive Design** — Designed with adaptable layouts where implemented.
- **Fast Development** — Powered by Vite and its development server.

> Note: The feature list should reflect the functionality currently implemented in the repository.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- [Git](https://git-scm.com/)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Abdo1454/nexus-admin-dashboard.git
   ```

2. Navigate to the project directory:

   ```bash
   cd nexus-admin-dashboard
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Production Build

To create a production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
